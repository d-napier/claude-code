Framework 02 // Prompting Hierarchy

Prompting split into four disciplines.
Your teams know one.

L4
Specification Engineering
Agent-executable documents across the org. Weeks/months horizon. Your entire document corpus is a specification.
L3
Intent Engineering
Encoding organizational purpose, trade-off hierarchies, decision boundaries. Klarna: 2.3M agent conversations, wrong objective.
L2
Context Engineering
Curating the token environment. Your 200-token prompt = 0.02% of the context window. The other 99.98% is this layer.
L1
Prompt Craft
Table stakes. The equivalent of typing in 1998.

Failure escalation: A bad prompt wastes a morning. Bad intent engineering (L3) damaged Klarna's customer trust for months. Bad specification engineering (L4) compounds across every agent in the organization.

Engagement // 90-Day Plan

Three questions. Five actions.
One decision that compounds
every quarter.

Three C-Suite Questions

  1. Where is understanding accumulating? If engineering uses Claude, product uses ChatGPT, analytics uses Gemini -- you're building silos, not intelligence.
  2. Are you running a flywheel? Compound improvement, or just people trying things?
  3. What is your switching cost? If you've built 25% of a context layer internally, at what point would you migrate?

Five 90-Day Actions

  1. Harness architecture review. Strategic commitment, not procurement. Map compounding lock-in timeline.
  2. Appoint frontier operations leads. Explicit roles for boundary-tracking and workflow redesign.
  3. Audit docs for agent readability. OKRs, strategy, product docs should be agent-executable specs.
  4. Build a shared context layer. MCP + vector DB. Eliminate the sticky-notes problem.
  5. Maximize feedback density. 10 real tasks/day to agents beats a 40-hour AI course.
