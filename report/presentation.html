Framework 02 / The Four-Level Prompting Hierarchy

Prompting has split into
four distinct disciplines.
Your teams know one.

Level 4
Specification Engineering
Agent-executable documents across the org. Time horizon: weeks/months. Your entire document corpus is a specification.
Level 3
Intent Engineering
Encoding organizational purpose, trade-off hierarchies, decision boundaries. Klarna's $2.3M agent disaster: perfect context, wrong intent.
Level 2
Context Engineering
Curating the token environment. Your 200-token prompt = 0.02% of the context window. The other 99.98% is this layer.
Level 1
Prompt Craft
Writing clear instructions. Table stakes in 2026 -- the equivalent of typing in 1998.

Critical insight: Failure severity escalates with each level. A bad prompt wastes a morning. Bad intent engineering at Level 3 damaged Klarna's customer trust for months. Bad specification engineering at Level 4 compounds across every agent in the organization.

Framework 02 / Five Specification Primitives

The learnable building blocks of specification engineering

01

Self-Contained Problem Statements

Can you state a problem with enough context that the task is plausibly solvable without the agent fetching more information?

02

Acceptance Criteria

Three sentences an independent observer could use to verify the output without asking any questions.

03

Constraint Architecture

Musts, must-nots, preferences, and escalation triggers. The best claude.md files: every line earns its place.

04

Decomposition

Subtasks under 2 hours each. Clear input/output boundaries. Independently verifiable. This is the granularity agents work best at.

05

Evaluation Design

3-5 test cases with known good outputs, run periodically -- especially after model updates. The only defense against regression.

"A lot of what people in big companies call politics is actually bad context engineering for humans." Toby Lutke, CEO Shopify -- referenced across multiple analyses

Framework 03 / Frontier Operations

The first workforce skill
in history that expires
quarterly.

AI capability is an expanding bubble. The surface area -- where human judgment matters -- grows with every model release. Five simultaneous skills define who operates at that frontier.

01

Boundary Sensing

Maintaining accurate intuition about where the human-agent boundary sits. Updates with every model release. Calibrated in November ≠ calibrated in February.

02

Seam Design

Structuring handoffs between human and agent phases. Clean, verifiable, recoverable. The seam that was right last quarter is wrong this quarter.

03

Failure Model Maintenance

Not "be skeptical." Differentiated: for task type A, failure mode is X, check Y. For task type B, failure mode is Z, check W.

04

Capability Forecasting

Reading the trajectory to make 6-12 month bets. Not prediction -- probabilistic positioning. Like a surfer reading swells.

05

Leverage Calibration

2-5 humans supervising 50-100 agents. 8 hours, 100 output streams. The skill is triaging your own attention in real time.

Framework 05 / The Four Compound Bets

The company that owns
the synthesis layer owns
the enterprise.

Four capabilities must work together. Failure of any one causes the entire multi-hundred-billion-dollar bet to collapse.

01

Intelligence x Context

Reasoning determines how much context can be productively used. The relationship is multiplicative, not additive. If reasoning plateaus, the context layer degrades from institutional memory to an expensive RAG pipeline that hallucinates organizational knowledge.

02

Memory That Doesn't Rot

Must maintain, resolve contradictions, deprecate stale knowledge, track current vs. superseded vs. historical-but-relevant. This is an open research question, not an engineering problem with a known solution.

03

Retrieval at Scale

Finding 2,000 relevant tokens in 10 trillion. Relevance defined by causal chains across 8 months. Current RAG cannot solve this. Requires hybrid: structured indexing, temporal tracking, hierarchical memory.

04

Execution at Speed of Trust

5% per-task failure rate compounds into systemic risk. Target: 99.5%+ accuracy sustained across diverse tasks including ambiguous, contradictory, or incomplete organizational context.

OpenAI Top-down. $600B+ infrastructure. Stateful runtime with AWS.
Anthropic Bottom-up. Organic context from 50%+ enterprise coding market.

Engagement Framework / 90-Day Action Plan

Three questions.
Five actions.
One decision that
compounds every quarter.

Three Strategic Questions for the C-Suite

  1. Where is your understanding accumulating? If engineering uses Claude, product uses ChatGPT, and analytics uses Gemini, you're building separate context silos, not shared organizational intelligence.
  2. Are you running a flywheel? Is there compound improvement in your AI systems -- or are people just trying things? Is retrieval getting better? Is execution getting more reliable?
  3. What is your understanding switching cost? If you've built 20-30% of a context layer internally, at what point would you switch to an enterprise offering? How portable is it?

Five Actions for the Next 90 Days

  1. Conduct a harness architecture review. Treat this as a strategic commitment, not a procurement decision. Assess switching costs by business unit. Map the compounding lock-in timeline.
  2. Appoint frontier operations leads. Create explicit roles for people who track the human-agent boundary, maintain failure models, and redesign workflows as capabilities shift.
  3. Audit your document corpus for agent readability. Start specification engineering. Your corporate strategy, OKRs, and product docs should be agent-executable.
  4. Build a shared context layer. Deploy cross-tool memory infrastructure (MCP + vector DB). Eliminate the five-sticky-notes problem. Establish one source of organizational understanding.
  5. Maximize feedback density. 10 real tasks delegated daily to agents beats a 40-hour AI course. Build practice environments. Measure calibration, not knowledge.

The Decision That Compounds

Every quarter your team builds more infrastructure around your current architecture. Every quarter the switching cost goes up. Every quarter the gap between frontier operators and everyone else widens. The cost of waiting another quarter is not linear. It's exponential.
